# Story 8.1.2: Sistema de Filtros e Busca

Status: **done**

## Story

Como admin, quero filtrar e buscar clientes por diferentes critérios, para encontrar clientes específicos rapidamente.

## Acceptance Criteria

1. [x] Deve ser possível filtrar por status do cliente (ativo/inativo)
2. [x] Deve ser possível filtrar por data de cadastro (intervalo)
3. [x] Deve ser possível filtrar por número de pedidos (min/max)
4. [x] Deve haver busca global por nome, email ou telefone
5. [x] Os filtros devem ser combináveis (AND lógico)
6. [x] A busca deve ser case-insensitive e com fuzzy matching
7. [x] Deve haver feedback visual quando nenhum resultado for encontrado
8. [x] Os filtros devem ser persistentes entre navegações

  - [x] Otimizar queries com índices apropriados
