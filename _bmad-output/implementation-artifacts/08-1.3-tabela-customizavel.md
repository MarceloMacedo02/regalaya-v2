# Story 8.1.3: Tabela com Colunas Customizáveis

Status: **done**

## Story

Como admin, quero customizar quais colunas da tabela de clientes são exibidas, para personalizar minha visualização conforme minha necessidade.

## Acceptance Criteria

1. [x] A tabela deve ter colunas padrão: ID, Nome, Email, Telefone, Pedidos, Total Gasto
2. [x] Deve ser possível mostrar/esconder colunas individualmente
3. [x] Deve houver um modal de configuração de colunas
4. [x] As preferências de colunas devem ser salvas por usuário
5. [x] As preferências devem ser restauradas automaticamente
6. [x] A ordem das colunas deve ser mantida personalizada
7. [x] Deve haver feedback visual quando colunas são alteradas
8. [x] A tabela deve permanecer funcional com qualquer combinação de colunas
