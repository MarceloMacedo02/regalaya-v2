# Story 8.2.1: Página de Perfil do Cliente

Status: ready-for-dev

## Story

Como admin, quero acessar uma página de perfil detalhada de cada cliente, para ter uma visão completa do cliente em um só lugar.

## Acceptance Criteria

1. [x] A página deve ser acessível clicando no nome do cliente na listagem
2. [x] Deve exibir informações básicas: foto, nome, email, telefone, data de cadastro
3. [x] Deve mostrar o segmento atual do cliente (VIP, Novo, Inativo)
4. [x] Deve exibir resumo de métricas: LTV, frequência de compra, última compra
5. [x] Deve haver navegação por abas: Resumo, Pedidos, Métricas
6. [x] A página deve ser responsiva e funcionar em mobile
7. [x] Deve haver botão de voltar para a listagem
8. [x] Deve haver opção de editar informações básicas do cliente

### Technical Decisions

- **Backend:** Spring Boot + JPA com queries otimizadas (JPQL/Criteria)
- **Frontend:** Next.js 14 App Router + TypeScript + Tailwind CSS
- **Gráficos:** Recharts (ResponsiveContainer, AreaChart, BarChart)
- **Cache:** Spring Cache abstraction (Redis recomendado)
- **Paginação:** Server-side com Pageable
- **Exportação:** CSV gerado no frontend (blob)
- **Segmentação:** Regras baseadas em LTV (>R$1000) ou pedidos (>10) para VIP; <3 meses para Novo; >6 meses para Inativo
