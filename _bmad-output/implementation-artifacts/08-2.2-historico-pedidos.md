# Story 8.2.2: Histórico Detalhado de Pedidos

Status: review

## Story

Como admin, quero ver o histórico completo de pedidos de cada cliente, para entender o comportamento de compra e padrões.

## Acceptance Criteria

1. [x] A aba Pedidos deve listar todos os pedidos do cliente
2. [x] Cada pedido deve mostrar: data, valor total, status, quantidade de itens
3. [x] Deve houver filtros por status de pedido (Pendente, Pago, Enviado, Entregue)
4. [x] Deve houver filtros por período de data
5. [x] Deve houver busca por nome do produto
6. [x] Deve houver ordenação por data (mais recente primeiro)
7. [x] Deve houver opção de ver detalhes completos do pedido
8. [x] Deve houver exportação do histórico para CSV

### Technical Decisions

- **Filtros:** Implementados via query params (não Specification devido à complexidade de busca por produto em itens)
- **Ordenação:** Server-side via Pageable com Sort.Direction
- **Exportação:** Frontend gera CSV do blob retornado pelo backend
- **Modal:** Reutiliza OrderDetailResponse do módulo de orders existente
- **Performance:** Query otimizada com JOIN FETCH para evitar N+1
