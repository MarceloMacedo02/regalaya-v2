# Story 8.2.3: Sistema de Métricas e Segmentação

Status: review

## Story

Como admin, quero ver métricas detalhadas e segmentação automática de clientes, para entender perfis e comportamentos de compra.

## Acceptance Criteria

1. [x] Deve calcular e exibir LTV (Lifetime Value) total do cliente
2. [x] Deve calcular frequência média de compras
3. [x] Deve mostrar tempo desde a última compra
4. [x] Deve segmentar automaticamente: VIP, Novo, Inativo
5. [x] Deve exibir valor médio por pedido
6. [x] Deve mostrar categoria de produtos mais comprada
7. [x] Deve haver tags visuais com cores para cada segmento
8. [x] As métricas devem ser atualizadas em tempo real

## Tasks / Subtasks

- [ ] Backend: Implementar cálculo de métricas
  - [ ] Criar CustomerAnalyticsService
  - [ ] Calcular LTV: soma de todos os pedidos do cliente
  - [ ] Calcular frequência: total_pedidos / meses_desde_primeira_compra
  - [ ] Calcular valor médio por pedido: LTV / total_pedidos
  - [ ] Identificar categoria mais comprada
  - [ ] Otimizar cálculos com queries agregadas
- [ ] Backend: Implementar lógica de segmentação
  - [ ] Criar regras de segmentação:
    - VIP: LTV > R$1000 ou > 10 pedidos
    - Novo: Primeira compra nos últimos 3 meses
    - Inativo: > 6 meses sem compra
  - [ ] Atualizar segmentação automaticamente
  - [ ] Histórico de mudanças de segmento
  - [ ] APIs para recálculo manual
- [ ] Frontend Admin: Implementar cards de métricas
  - [ ] Criar componente MetricCards.tsx
  - [ ] Exibir LTV com formatação monetária
  - [ ] Mostrar frequência com unidade adequada
  - [ ] Exibir tempo desde última compra
  - [ ] Destacar valor médio por pedido
  - [ ] Adicionar tooltips explicativos
- [ ] Frontend Admin: Implementar sistema de tags
  - [ ] Criar componente CustomerSegmentTags.tsx
  - [ ] VIP: Tag dourada com cor "#FFD700"
  - [ ] Novo: Tag verde com cor "#22C55E"
  - [ ] Inativo: Tag cinza com cor "#6B7280"
  - [ ] Adicionar tooltips com detalhes do segmento
  - [ ] Implementar animação suave ao mudar segmento
