# Story 8.2.4: Gráficos e Visualização de Dados

Status: review

## Story

Como admin, quero ver gráficos interativos que mostram o comportamento de compra dos clientes, para identificar padrões e tendências.

## Acceptance Criteria

1. [x] Deve houver gráfico de evolução do LTV ao longo do tempo
2. [x] Deve houver gráfico de frequência de compras por mês
3. [x] Deve houver gráfico de distribuição de valor médio por pedido
4. [x] Deve houver gráfico de categorias de produtos mais compradas
5. [x] Todos os gráficos devem ser interativos e exportáveis
6. [x] Deve houver opção de selecionar período de análise
7. [x] Deve houver hover com detalhes nos gráficos
8. [x] Os gráficos devem ser responsivos e funcionar em mobile

## Tasks / Subtasks

- [ ] Backend: Implementar dados para gráficos
  - [ ] Criar endpoint GET /admin/customers/{id}/analytics
  - [ ] Preparar dados para gráfico de evolução de LTV
  - [ ] Agregar dados por mês para frequência de compras
  - [ ] Calcular distribuição de valores médios por pedido
  - [ ] Contar produtos por categoria mais comprados
  - [ ] Permitir filtro por período de análise
- [ ] Backend: Otimizar queries analíticas
  - [ ] Criar queries otimizadas para agregações
  - [ ] Implementar cache de 30 minutos para dados analíticos
  - [ ] Adicionar limites de dados para evitar sobrecarga
  - [ ] Validar períodos de análise (máximo 24 meses)
- [ ] Frontend Admin: Implementar biblioteca de gráficos
  - [ ] Integrar Recharts ou Chart.js
  - [ ] Criar componente BaseChart.tsx reutilizável
  - [ ] Configurar tooltips interativos
  - [ ] Implementar exportação para PNG/SVG
  - [ ] Adicionar loading states para gráficos
- [ ] Frontend Admin: Implementar gráficos específicos
  - [ ] Gráfico de linha: Evolução do LTV (LineChart)
  - [ ] Gráfico de barras: Frequência por mês (BarChart)
  - [ ] Gráfico de pizza: Distribuição de valores (PieChart)
  - [ ] Gráfico de barras horizontal: Categorias mais compradas (BarChart)
  - [ ] Todos com interatividade e exportação
