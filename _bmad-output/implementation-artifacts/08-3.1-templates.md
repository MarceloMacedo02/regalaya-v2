# Story 8.3.1: Sistema de Templates de Comunicação

Status: ready-for-dev

## Story

Como admin, quero criar e gerenciar templates de comunicação reutilizáveis, para padronizar minhas mensagens e garantir consistência.

## Acceptance Criteria

1. [x] Deve houver um gerenciador de templates com CRUD completo
2. [x] Templates devem suportar variáveis personalizáveis: {{nome}}, {{produto}}, {{valor}}
3. [x] Deve houver templates pré-definidos para diferentes ocasiões
4. [x] Deve houver editor visual para templates de email
5. [x] Deve houver pré-visualização em tempo real
6. [x] Templates devem ser versionados com histórico
7. [x] Deve houver importação/exportação de templates
8. [x] Templates devem ser validados antes de usar

## Tasks / Subtasks

- [x] Backend: Implementar gerenciamento de templates
  - [x] Criar tabela communication_template com CRUD completo
  - [x] Estrutura: id, name, type (EMAIL/WHATSAPP), content, variables, created_at
  - [x] Implementar endpoint CRUD: GET/POST/PUT/DELETE /admin/templates
  - [x] Criar serviço TemplateService com lógica de validação
  - [x] Implementar versionamento de templates
- [x] Backend: Implementar sistema de variáveis
  - [x] Criar classe TemplateVariable com parser
  - [x] Suportar variáveis: {{nome}}, {{email}}, {{telefone}}, {{produto}}, {{valor}}
  - [x] Validar sintaxe de variáveis nos templates
  - [x] Implementar substituição segura de variáveis
  - [x] Criar sistema de validação de templates
- [x] Frontend Admin: Implementar gerenciador de templates
  - [x] Criar página TemplatesPage.tsx com tabela de templates
  - [x] Implementar CRUD completo: criar, editar, deletar, visualizar
  - [x] Adicionar filtros por tipo (email/whatsapp)
  - [x] Implementar busca por nome ou conteúdo
  - [x] Adicionar botões de importação/exportação
- [x] Frontend Admin: Implementar editor visual
  - [x] Integrar TinyMCE ou Quill.js para rich text
  - [x] Criar componente TemplateEditor.tsx
  - [x] Suportar drag-and-drop para imagens
  - [x] Implementar autocomplete de variáveis
  - [x] Adicionar preview em tempo real
