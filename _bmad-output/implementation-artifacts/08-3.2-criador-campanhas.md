# Story 8.3.2: Criador de Campanhas Passo a Passo

Status: ready-for-dev

## Story

Como admin, quero usar um criador de campanhas intuitivo com wizard passo a passo, para criar e configurar comunicações em massa facilmente.

## Acceptance Criteria

1. [x] Deve houver um wizard com 4 passos claros e intuitivos
2. [x] Passo 1: Seleção de clientes (todos, segmento, filtros personalizados)
3. [x] Passo 2: Escolha de tipo de comunicação (email/whatsapp)
4. [x] Passo 3: Seleção e personalização de template
5. [x] Passo 4: Agendamento e confirmação final
6. [x] Deve houver validação em cada passo
7. [x] Deve houver preview da campanha antes de enviar
8. [x] Deve houver opção de salvar rascunho

## Tasks / Subtasks

- [x] Frontend Admin: Implementar wizard navigation
  - [x] Criar componente CampaignWizard.tsx
  - [x] Implementar sistema de navegação entre passos
  - [x] Adicionar barra de progresso visual
  - [x] Implementar validação de cada passo
  - [x] Permitir voltar e avançar entre passos
  - [x] Salvar estado do wizard no localStorage

  - [x] Criar componente CustomerSelectionStep.tsx
  - [x] Opção: "Todos os clientes"
  - [x] Opção: "Por segmento" (VIP, Novo, Inativo)
  - [x] Opção: "Filtros personalizados" (RFM, valor gasto, etc.)
  - [x] Implementar seleção avançada com múltiplos critérios
  - [x] Exibir contador de clientes selecionados

  - [x] Criar componente CommunicationTypeStep.tsx

## Dev Notes

- Relevância: Wizard intuitivo é essencial para adoção da ferramenta por não técnicos
- Prioridade: Alta - impacta diretamente a usabilidade do sistema
- UX: Interface clara com validação em tempo real e feedback visual
- Performance: Carregamento rápido de templates e clientes
